# Events page redesign (`/events`)

Objective: rebuild `/events` as the single public agenda: calendar on the left, a compact banner per special event, a timeline of collapsible event cards with big game covers and a visual seat counter. The "Properes sessions" and calendar sections of `/profile` are removed.
Branch: `feat/events-redesign` (from `develop`). Delivery: `ask-on-risk`, `feature-branch-chain` (assumption, same as the badge catalogue and member benefits): one work-unit commit per task on this branch, merged into `develop` when the user says so. Test runner: Vitest (`npm run test:unit`), Playwright (`npm run test:e2e`, `LUDOYA_MOCK=1`).

## How to start or resume (new session)

Prompt for a new session: **"Continúa la feature events-redesign (odd/tasks/events-redesign.md): siguiente tarea pendiente."**

1. `mem_context`, then `mem_search` "events-redesign" (project `darkstone-cat`), then read this file to the end of `## Log`.
2. `git switch feat/events-redesign` (create it from `develop` if it does not exist, carrying this file and the mockup folder).
3. Take the first task in `## Tasks` whose status is not `done`, implement it test-first, run its checks, commit it (Conventional Commit), set its status and commit here, append a Log line and update the Engram mirror `odd/events-redesign/tasks`.
4. Continue with the next task in the same session while context allows. Stop and ask only for a real product decision.

Design reference (approved, L14): `odd/tasks/events-redesign-mockup/` (`desktop.dc.html`, `mobile.dc.html`, `seats.dc.html`: plain HTML plus a `renderVals()` script holding the example data and every rule; `canvas.json` notes hold the UX rules). Live canvas: https://claude.ai/artifact/AwMxuDH43Wck4C3bpLXm3Y (private to the owner). The mockup texts are Catalan; production copy goes to `src/messages/{ca,es,en}.json`.

## Specs

- **S1 Page structure (proposal B).** User: "me quedo con el enfoque B, con el calendario a la izquierda y un banner al inicio con cada evento especial." Desktop: short dark header (h1 "Esdeveniments", one line of text, chips with session hours, venue link, "Gratuït · no cal ser soci"), the special-event banners, then two columns: a sticky calendar sidebar (left, with legend and a "Com funciona" card) and the timeline (right). Footer and NavBar as today. JSON-LD (BreadcrumbList, WebPage, Event per event) is kept.
- **S2 No section link bar.** User: "La especie de cabecera con links de \"aquesta setmana\", \"properes setmanes\" y \"especials\" no me parece útil dado que se puede visualizar rápido, eliminala". There is no sticky section navigation, on desktop or mobile.
- **S3 Special-event banners.** User: "EL banner deberia ser mas pequeño, de los numeros a mostrar con poner los dias restantes estaria bien." One compact banner (about 110 px desktop, 96 px mobile) per upcoming special event, newest first, at most 3: small image, "Esdeveniment especial", title, dates and place, and on the right only the days left ("Falten N dies"). Clicking it opens the special's card in the timeline and scrolls to it. No specials → no banner.
- **S4 Timeline and collapsible cards.** User: "Todo evento deberia ser deplegable y verse como lo actual de la semana, solo que los eventos para semanas siguientes deben aparecer por defecto siempre contraidos, y solo los especiales expandidos." Every event (session or special) is a card with the same format and a toggle (`aria-expanded`, `aria-controls`). Defaults: this week's events open, events of later weeks closed, special events always open. A closed session card shows title, date and time, play count, free seats and a stack of small covers. Each later week has "Desplega-ho tot / Plega-ho tot". The open card shows the plays grid plus a "Proposa una partida" card (Ludoya link). A session without plays says "Encara sense partides" and the propose card says "Sigues el primer!".
- **S5 Range.** User chose "4 semanas + especiales (Recomendada)": the timeline groups by Madrid weeks (Monday to Sunday): this week ("Aquesta setmana", with total plays and free seats) and the 3 following weeks ("Setmana del 16 al 22 de novembre"), plus every special event of the next 12 months even when it falls later (in its own week group). A multi-day special that already started stays while it runs. "Veure més dates a Ludoya ↗" closes the list.
- **S6 Plays grid and seat counter.** User: "Partidas en cuadricula parece correcto." and "se podria hacer un sistema con iconos de sillas, sillas negras son ocupadas y sillas blancas libres. Algo que sea mas visual, por que si solo se dice la gente que falta queda extraño, a veces interesa cuanta hay apuntada." and "me gustaria que este en la parte de arriba de la imagen de juego como la pildora anterior, si es necesario añadelo a una pildora para asegurar el contraste" and "En el caso de muchas sillas, podriamos usar una elipsis, o algo parecido, y hacerlo en una sola linea, con el contador X/N siempre visible a la derecha". Play card: 3:4 cover, a light pill at the top of the cover (`rgba(250,250,249,0.96)`, small shadow), the time and game name on a dark strip at the bottom, a status line below the cover and the "Apunta't ↗" / "A la cua ↗" button. The pill, on one line, with the counter `X/N` always visible on the right:
  - capacity ≤ 8: chairs (filled dark = taken, grey outline = free, orange outline = still needed to reach `minParticipants`); at most 6 chairs on desktop and 5 on mobile, otherwise the first MAX-1 chairs (taken, then needed, then free) and "…";
  - 9-20: a segmented bar (one segment per seat; taken dark, needed light orange, free grey `#BDB7B0`);
  - more than 20: a continuous bar;
  - no capacity: a people icon and "N apuntats".
  - Status line, by priority: "Completa", "Falta 1 per començar" / "Falten N per començar", "Queda 1 plaça", "Queden N places", "Sense límit de places". The pill is `role="img"` with an `aria-label` such as "3 de 4 places ocupades, en falta 1 per començar".
  - The reference sheet `seats.dc.html` lists every case.
- **S7 Usual venue omitted.** User: "Si la ubicacion del evento es el de la asociación este deberia omitirse." A card shows the place only when `place.isUsual` is false (with "fora del local habitual" and a "Com arribar-hi ↗" maps link); the usual venue appears only in the header.
- **S8 Countdown only on specials.** User: "La indicación de \"Faltan X Dias\" no es necesaria en los eventos recurentes, solo en los especiales." Texts: "Falten N dies", "Demà", "Avui", "En curs" (multi-day special already started). Never on sessions, nor in the mobile day strip.
- **S9 Calendar.** Desktop: the month grid in the sticky sidebar (session days dark, special days orange, today ringed, past days faded); clicking a day with a loaded event opens that card and scrolls to it (update the URL hash); a day with an event outside the loaded range opens Ludoya. Month navigation from the current month up to 6 months ahead; changing the month never moves the timeline.
- **S10 Mobile calendar.** User: "En movil quizá se podria incluir y hacer que el calendario este abajo o hacerlo deplegable. Analiza cual seria la mejor forma, dado que lo mas visual es tener las partidas del proximo dia antes que otras cosas" and "El calendario en fila no debe tener barra de scroll, que tenga algo mas visual que si pueda moverse mediante gestos de dedos". Order on mobile: header, banners, "Properes dates" strip, timeline, "Com funciona". The strip shows only upcoming days with events (this week dark, later white, specials orange), swipes with the finger, has no visible scrollbar, snaps per day, shows a partially visible last day with a right-edge fade and "›" (hidden at the end), a week label above the first day of each week, and position dots. Tapping a day opens and scrolls to its card. "Veure el mes ▾ / Amaga el mes ▴" expands the full month grid (closed by default).
- **S11 Fresh seat data.** Seat counts must not be a day old: `/events` reads the same 60 s Ludoya request as today's member area (`fetchMemberAreaSessions`, stale-while-revalidate) instead of `eventsRevalidateSeconds` (24 h). Covers go through the existing BGG matching with its time budget. Only `PUBLIC` sessions and plays are shown. Organizer names are never sent to the browser.
- **S12 Remove the profile sections.** User: "Esas secciones en profile deben eliminarse, careceran de sentido y seria duplicarlas." and, for what replaces them, "Nada". Remove "Properes sessions" and the month calendar from `/profile` with no replacement, plus their code, route, messages and tests when nothing else uses them (code that `/events` reuses moves rather than disappears).
- **S13 Deferred.** User chose "Dejarlo para después" for "Afegeix al calendari" (`.ics`): not in this feature.
- **S14 Untouched.** The admin event image tool (`/admin/tools/event-images`, `/api/events/[eventId]/image`) keeps `fetchUpcomingEvents` and its 24 h cache.
